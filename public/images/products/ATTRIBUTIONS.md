## Incomplete records (34 files)

The sourcing script fetched, license-filtered, and saved every image below the same
way as the ones documented above, but a handful of the batch runs that fetched
multiple sectors at once hit this tool's 2–3 minute command timeout *after* the image
files were already written to disk but *before* the script's final metadata write —
so the pixel data is safely saved and was visually verified during review, but the
specific source URL/author for these particular files was lost, not fabricated here.
All were license-filtered the same way (Public Domain, CC0, CC BY, or CC BY-SA only)
before being accepted.
