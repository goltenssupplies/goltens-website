# sections/

Page-section-level components mapped 1:1 to the sections named in the Home
Page Design Specification and the approved page mockups: Hero, WhoWeServe,
HowWeExecute, SupplierNetwork, ComplianceRegistration, etc.

- Composed from `ui/` primitives; own their section's copy and layout only.
- Grouped by page where useful, e.g. `sections/home/`, `sections/about/`.
- Built in a later sprint. No components exist here yet.
